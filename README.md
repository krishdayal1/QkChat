# 💬 QkChat

A full-stack real-time chat application built with the MERN stack, featuring secure authentication, real-time messaging, image sharing, online user status, and Astra — an integrated AI assistant.

## ✨ Astra AI Assistant

Astra is QkChat's built-in AI companion designed to provide intelligent and interactive responses directly within the chat application.

Astra supports:

- AI-powered conversations
- Markdown-formatted responses
- Syntax-highlighted code blocks
- Clickable links
- Responsive chat interface
- Animated thinking indicator

## 🚀 Features

### 💬 Real-Time Messaging

- Send and receive messages instantly using Socket.IO
- Real-time online and offline user status
- Responsive chat interface
- Image sharing between users

### 🔐 Authentication

- Secure user signup and login
- JWT-based authentication
- Password hashing using bcryptjs
- Protected backend routes

### 🤖 Astra AI Companion

- Integrated AI assistant powered by Gemini
- Markdown response rendering
- Syntax highlighting for multiple programming languages
- Scrollable code blocks for long code
- Animated AI thinking indicator
- Responsive AI chat interface

### 🎨 User Experience

- Responsive design for desktop and mobile devices
- Multiple themes using DaisyUI
- Toast notifications
- Automatic chat scrolling
- Global state management with Zustand
